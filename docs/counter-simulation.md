## 模式边界

单挑：道中目标用区域最高等级，当前目标用实际血量/状态和倍率；保留原道馆完整队伍规模，其他成员标记已倒下，不能把道馆倍率误按一只敌人重新计算。指定目标默认普通野生战。满血开关只影响我方，关闭保留实际 HP/状态；单挑重新排队列。

路线：按保存的节点连续执行，冻结读取时刻的时钟与天气，正常保留状态和中心治疗。每一次击倒都不发经验或触发升级/进化，终局跳过捕获和金钱；升级不会在路线内部悄悄发生。队伍假设从当前节点起生效，保留已有敌方队列。等待选择、特殊首领、特殊区域、超过行动上限的样本明确报错，不计为胜利或失败。

排序：游戏自动切换评分只看攻击克制与防守抗性，已在场加 0.001，同分遵循当前实际队伍顺序。实际队伍来自 road / activeTeam，不能直接按整个 box 排列。四只以内全排列，五六只仅基线加两两换位；两种自动切换模式都比较，不直接写游戏设置。排序是假设分析；不承诺排名统计显著或全排列最优。

## 统计口径

- 最终缺血：`1 - 结束剩余HP / 初始最大HP`，失败样本同样计入。不会用仅胜利时剩余血量冒充期望战损。
- 累计承伤：逐条 HP 变化累计实际扣血，剔除溢出，包含自伤、状态伤害；治疗和吸取同步基线，中心治疗不会掩盖已付出的战损。
- 累计倒下次数（中心复活不清零）、攻击行动数、获胜样本的伤害命中次数分布分开报告。
- 行动速度和非暴击命中伤害区间由原函数确定；状态招式仍可能取代伤害招式。当前低血目标还会触发原引擎的高命中补刀选招。
- 概率分支逐条执行，不把随机值替换成平均数。完整期望是抽样估计，附种子、数量与置信区间，绝不标成精确解析期望。
- 胜率：Wilson 95% 区间；有界期望缺血：经验 Bernstein 95% 区间，样本方差为零也保留不确定性；无界累计承伤/行动数：近似均值区间。
- 达标：胜率下界达到用户阈值，战损上界低于用户阈值。区间按单组计算，多方案选择存在选择偏差；逐级扫描不使用单调性假设。

## 验证与更新

`npm run test:engine` 下载固定公开构建到忽略的缓存，校验后运行真实引擎集成测试。`npm run test:browser` 通过本地拦截官方资源，把同一真实构建送入实际 Worker，检查迁移、读取、矩阵、排序、取消和游戏存档不变。

更新引擎前审查新版本数据结构、工厂闭包依赖、私有查询函数和终局事件位置，更新完整摘要与适配器，补充回归。不得删除摘要校验、自动接受未知版本，或使用简化原作战斗公式代替。

旧的前三代公开快照仅用于早期调查，已不参与本模块的计算。当前线上规则不使用性格，也不使用原作招式优先度；不把此前口头建议当作引擎规则。
