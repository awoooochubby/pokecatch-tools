# 直接模拟经验效率（v2.3.0）

点击助手顶部「刷图」→「模拟选图」→读取当前队伍→勾选地图→模拟比较。默认会选当前章，以及本地区已解锁的银河队基地、灯塔徽章、冠军之路；可以改成其他普通章节。每次比较前自动刷新存档和游戏版本，不需要先去每张地图挂机采集。

## 战斗和经验

独立 Worker 加载经完整 SHA-256 核验的 Game / Adventure 工厂，在克隆存档中从章首执行。保留当前 road 顺序、自动切换、伙伴、强化、闪光、地区限制和经验增益。可选择满血或把当前 HP / 状态带到章首，路线中的中心、果树和其他正常治疗照原引擎执行。

不同于战损矩阵的固定等级模式，本模式允许原引擎实际升级，所以本轮升级后的速度、血量、招式和伤害也会变化。不会自动确认进化或使用道具。每个随机样本都从同一份当前经验和等级开始，不把上一样本的升级带到下一样本。

每次 Adventure.step 前后读取原队伍各成员的经验、等级，将消耗的原始 xpForNext 加回；不只统计 type=xp 奖励事件。这样会计入调用私有 XP 函数的伙伴糖果和重复捕获，也会正确丢弃触顶溢出。只计快照已有的出战成员，未计整个 Box。不同地图可能因自动捕获而得到不同的家族经验，所有处理留在克隆中。

完整走完节点或第一次原引擎 defeat 回城治疗时结束该次尝试。失败前已获得的经验和失败时间全部计入。少数已打过馆主的战败可原生放行，此时按原引擎能否走完节点统计“完成率”，而非声称每个敌人都被击倒。倒下次数是 HP 穿过零的累计次数，中心复活后再倒下会重复计入。

到达章末后在提升章节解锁进度前停止，补计一个循环/出发行动步；下一样本仍保持当前进度上限。预测的是“以当前状态出发的一轮”的期望，非等级不断变化后的长期稳态。

## 耗时与排名

原游戏在在线状态下、当前未显示冒险页面时，采用 `max(上次动画均值, STEP_MS) / Adventure.speed()` 的步进节奏。未观察过动画的初始均值为 ACTION_MS。预测使用这一标准基线：

```
每步预计毫秒 = max(CONFIG.ACTION_MS, CONFIG.STEP_MS) / Adventure.speed()
一次尝试预计时间 = 实际 Adventure.step 数（含循环步） × 每步预计毫秒
XP/分钟 = 所有尝试总实得 XP / 所有尝试总预计毫秒 × 60000
```

当前 ACTION_MS=2800、STEP_MS=650。使用游戏 SPEED_PACE，而非简单除以界面标称倍数；例如标称 4 倍在当前构建对应实际行动节奏 2.5 倍。每一步按该现实时间推进独立 Clock，并累计 Adventure.addTime，故经验增益到期、昼夜和天气会随预测时间变化。

**此模型不是前台动画的精确计时，也不包含手动停顿、首次图鉴弹窗或进化确认。** 在线后台节奏本身也可能沿用玩家此前的动画均值；标准基线不推测该隐藏均值。不同地图的动画构成可能导致实际排名变化，实测记录可用于复核。无需实战采样就能先比较，但不能将预测秒数称为已测量的精确秒数。

必须用总经验除总时间，不能把每次 XP/分钟简单平均；后者会让短失败样本获得错误权重。整体与每个队伍成员分别保留配对经验/时间样本，使用残差方差给比率计算近似 95% 抽样区间。完成率附 Wilson 区间；其他均值使用近似区间。显示区间不包含计时模型误差，也不保证多个方案筛选后的整体覆盖率。

排行会随比较对象在整队/单只间切换，不需要重新模拟。预测最高只针对本次已完成的有效地图，接近的结果应提高模拟次数。失败和零收益都参与计算；需要手动选择或遇到未适配机制的地图显示原因，从排行中排除，不把不完整样本当作零收益。

## 边界与安全

- 支持当前钱包地区内已解锁的普通章节，跨地区钱包切换、活动、高塔、特殊区域暂不支持。
- 新生成路线未接入漫游首领模块；其他系统的被动收益未计入。
- 赠送、交易和其他手动选择没有安全默认答案时，停止该图，不猜测选择。
- 原游戏代码仅在 Worker 内执行，不调用网页中的 Game，不改游戏存档，不自动切图。下载引擎的请求不携带登录凭证或存档。
- 默认 256 次/图，允许 128–2048 次/图、最多 16 图、总共 8192 轮，每次尝试最多 20000 行动步；可取消，十分钟自动终止。
- 每次开算都会重新读取队伍；计算期间等级、经验、HP、伙伴、加成、物品或进度发生变化，结果标记为快照已过期。

导出的 JSON 含引擎版本、快照队伍摘要、比较条件、每图及每只成员的经验/速率、完成率、倒下次数和完整口径，不含完整游戏存档。
