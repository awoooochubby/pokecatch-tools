# PokeCatch Tools

经验统计与整轮战斗日志（初版 v0.1.1）。

## 安装

先安装 Tampermonkey，再点击 [安装脚本](https://raw.githubusercontent.com/awoooochubby/pokecatch-tools/main/pokecatch-stats.user.js)，确认安装，刷新游戏。如果链接只显示源码，可在 Tampermonkey 的实用工具中使用此 URL 安装。

已配置 @updateURL、@downloadURL 和版本号。请保持 Tampermonkey 的脚本更新检查开启；发布新版后扩展会按设置的周期检查，也可手动检查更新。更新后刷新游戏即可，无需再次粘贴代码。

## 功能

- 可拖动、折叠浮窗；队伍精灵经验速度和下一级时间估算。
- 使用存档 adv.runs 分组，默认保留 20 轮，可改为 1–100 轮。
- 日志 JSON 导出；历史仅保存在本机游戏域名的 localStorage。
- 不修改游戏存档、游戏函数或时间，不上传战斗记录。

## 当前限制

已核对公开前端字段并通过 JavaScript 语法检查，尚未完成登录后的实际战斗验收。

轮次使用游戏保存的 adv.runs，存在存档延迟；塔与特殊区域模式尚未适配。仅记录界面实际显示的战斗日志，离线或快速跳过的内容无法还原。中途接入、切换章节、漏过多轮或采样中断会标为不完整。每轮最多 3000 条日志，未完成的一轮刷新后不保留。

经验增量只累计同等级内可确认的值，跨级和轮次切换间隔不猜测；因此不是精确的全轮经验总量，糖果等非战斗来源也可能计入。预计时间采用最近最多 5 分钟的当前等级经验速度（含等待时间）与界面经验条估算；动画期间可能波动。换轮、升级后重新采样，至少 10 秒且有经验增长才给出预测。

## 维护

修改 pokecatch-stats.user.js 后提高 @version，并同步更新 pokecatch-stats.meta.js 中的元数据。保持这两个文件在 main 分支的固定路径即可自动更新。仓库不包含浏览器配置、账户信息或游戏存档。
