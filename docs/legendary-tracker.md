# 神兽挂机追踪

先在游戏里配好冒险队伍，打开助手“追踪”，读取目标与天气，选择想抓的神兽或天气限定精灵，按上下箭头调整优先级，最后点击“开始挂机捕捉”。目标选择和模式保存在本机。

可在“自动吃哪些果子”中选择挂机时自动使用的果子，显示原生效果倍率和当前库存。只消耗选中的果子，同类只保留最后选择的一种。没有同类效果或效果到期后，点击原生果子栏续吃；已有同类效果时不会覆盖或重复叠时长。库存不足时继续追踪并提示，补货后恢复续吃；没有可执行目标、游戏隐藏、弹窗等待或停止追踪时不消耗。不会自动购买果子，效果和扣库存由原生游戏结算。

追踪器操作游戏的地图按钮，战斗和捕获均由原版游戏执行。每两秒检查已保存的位置、所有权和天气。击倒不算抓到，捕获失败继续尝试；游走位置变化后自动跟随。已过游走遭遇节点或进图时还未生成游走节点，会通过另一个已解锁章节中转后重新进入。抓到后自动处理下一只；所有主目标完成后停止切图，游戏本身继续运行。

主目标优先使用选择顺序，不满足条件的暂时跳过，不会为等待一只锁住的精灵而停止其他可执行任务。普通定点神兽使用原生解锁和开放条件。周轮换形态、世界首领和需要解谜的入口不代为处理。

## 天气插队

“不允许插队”只处理选中的主目标。“允许插队”会检查已解锁地区的天气稀有怪：只考虑当前天气确实在原生遭遇池中激活、尚未拥有的物种，以及满足前置条件的天气定点遭遇，例如洛托姆形态。默认关注全部，也能只选少数物种。

优先处理即将结束的天气机会，同等条件优先当前地图及较高遭遇机会；开始捕捉某个天气目标后持续尝试，避免在多个机会间不停切图。抓到或天气失效后重新选择任务，继续主目标。这里的遭遇比例仅用于选择同类机会，不代表捕获成功率或战斗胜率。

## 队伍与运行条件

- 不改队伍、招式、道具、游戏时间、天气、随机数或战斗规则，不直接写入游戏存档；原生切图可能治疗队伍，原生战斗和捕获会正常结算收益及消耗。
- 存档中有战斗，或者界面仍显示存活敌人／捕获动画时，等结算后再切图。自动关闭捕获后的新图鉴／异色结果提示，避免抓到后卡在“继续”；其他游戏弹窗、未处理的赠礼／解谜选择会显示等待原因，需要手动处理。
- 开始时队伍必须已完成上场切换；地区限制可能阻止某些目标。神兽独立队伍须为空（使用冒险队伍）或与冒险队伍一致，否则等待。运行中手动换人、移除或重排会暂停；游戏将新捕获精灵自动填入原有空位时会继续追踪并记入日志。
- 游戏隐藏标签页时暂停实时战斗，离线结算不会触发游走遭遇。因此挂机时请让游戏标签页可见，可放到独立窗口。恢复可见后自动继续；系统休眠、浏览器冻结或关闭期间不运行。
- 刷新页面后不会自行恢复操作，需要重新读取并点击开始；目标与插队模式保留。打开另一个游戏标签页导致原生标签锁转移时停止追踪。
- 版本适配使用现有游戏构建及源文件校验；规则仅在独立 Worker 中读取，游戏私有模块不暴露也不注入改写。地图入口失效或读取超时会暂停，显示错误，不继续乱点。

## 验证

单元测试覆盖主目标顺序、实际捕获完成、游走迁移、天气插队与返回、过期机会、自选天气名单、节点错过重进、原生天气池及定点形态条件、寄养所有权、地区／独立队伍限制、停止与卸载、隐藏恢复和刷新后不自启。浏览器回归使用真实规则 Worker 和原生地图选择器契约验证多目标自动切图、战斗保护与队伍保留。额外使用隔离存档运行原版游戏，验证真实地图按钮可自动到达雷公位置，不使用登录账户。
