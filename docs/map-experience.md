# 刷图经验与两章比较（v2.2.0）

## 经验怎么算

当前官方构建 `cf8c0470ea` 的 Adventure 在每只敌人被击倒时，对实际出战队伍 `road` 的每只精灵分别计算：

```
原始奖励 = Game.levelXp(敌人等级) / 15 × sqrt(BASE_EXP[敌人种族] / 60)
入账请求 = round(原始奖励 × 训练家倍率 × 在场倍率 × 伙伴倍率 × 在线/离线倍率 × 经验增益)
```

训练家、道馆倍率 1.5，其余普通战斗 1；当次在场的精灵 1.1，后备 1；伙伴 1.3；在线 1，离线 0.5。增益按游戏当时的 `buffMult('xp')`。达到适用上限的精灵不获得经验；升到上限时剩余溢出会被丢弃。活动和高塔的处理不同，不套用普通路线规则。

当前这两章的 `levelXp(L)` 等于 `floor(0.8 × L^2.4 + 10)`。这是敌人等级的奖励基数，不是玩家升一级所需经验。玩家经验表还受进度地区、等级增长和强化阶数影响；奖励没有“玩家等级高于野怪就直接打折”的系数。低级地图能否更快，取决于实际通关时间。

伙伴击倒计数触发的糖果、重复捕获、经验道具另有奖励。因此战斗画面的 XP 飘字不能直接作为唯一的实际入账凭据：跨级和触顶会影响实际增长，而且重复捕获也会复用 XP 飘字。

## 浮窗统计口径

新浮窗以连续两个游戏存档为依据；同级取 XP 差，跨级加上原等级至新等级之间每一级实际消耗，再加新旧 XP 差。只统计 `road`，没有 `road` 时回退计划队伍，不统计整个 Box。触顶的溢出不会计入。

跨级公式的数据从固定摘要的官方引擎生成，已逐个核对 4 个地区 × 100 级 × 6 个强化阶数，与原始 Game.xpForNext 完全一致。页面脚本版本不匹配或无法识别时，同级仍可精确取差，跨级整段排除，不填入估算经验。

有效时长包括战斗动画、治疗、走图和正常等待，排除游戏暂停、后台、关闭页面、超过 15 秒的采样中断、地图/队伍/地区倍率变化，以及不能确认经验变化的区间。每个章节多轮合并。首次接入、重载和重新启用只建立基线，离线收入不挪到当前地图。指定精灵的分母只计算其实际参与队伍的观测时间。

统计的是实得经验，包含观测期间的重复捕获、伙伴糖果和手动道具，不能仅凭存档拆分所有来源。若只比较纯击倒效率，请保持捕获与道具使用条件一致。旧经验页仍保留其“墙钟时长/下界经验”的原统计口径，与新浮窗的有效观测口径不同。

## 银河队基地 vs 灯塔徽章

下面是**原引擎随机遭遇抽样得到的期望估计，不是解析精确解**。每种条件各生成 50,000 轮；取重复刷图那组记录。固定白天时刻 `2026-11-04 12:00 UTC`，Node 时区 UTC，使用原昼夜、天气与当天热点逻辑；无伙伴/经验增益，无漫游首领，假定完整击倒，计算未触顶精灵的奖励。仅击倒经验，不含重复捕获/糖果/道具。等级按每只敌人加权平均，经验按每一整场敌方队伍加权平均。

| 常规野怪战/轮 | 0 | 12 |
| 额外城镇野怪战/轮 | 0 | 约 0.20 |
| 普通/剧情训练家战/轮 | 7（6 银河队员 + 赤日） | 8 |
| 馆内训练家战/轮 | 0 | 3 |
| 首领/馆主战/轮 | 1（镇星） | 1（电次） |

灯塔的平均敌人高约 10.17 级，但由于混入大量单只野怪战，平均每场经验仅高约 **1.58%**。每轮约有 **3.073 倍**击倒经验：只有灯塔完整一轮的耗时小于银河基地的 3.073 倍时，它的纯击倒经验/分钟才更高。这个条件包含走图、治疗和动画耗时；若计入捕获等额外奖励，要以浮窗实测的实际总经验比较。不能仅凭敌人等级推荐灯塔。

## 银河队基地 vs 神奥冠军之路

沿用上述构建、白天、无额外加成、未触顶后备精灵的纯击倒口径，冠军之路（章节索引 59，含沿途 223 号水路）重新生成 50,000 轮。

| 指标 | 银河队基地 | 神奥冠军之路 |
| --- | ---: | ---: |
| 平均敌方等级 | 54.56 | 70.11 |
| 野怪战/轮 | 0 | 10 |
| 普通/剧情训练家战/轮 | 7 | 6 |
| 最后首领/对手战/轮 | 1 | 1（6 只精灵） |
| 总场数/轮 | 8 | 17 |
| 每场经验：每只后备精灵 | 约 2,785 | 约 4,079 |
| 每场经验：假设每次击倒都在场 | 约 3,063 | 约 4,487 |
| 每轮经验：每只后备精灵 | 约 22,281 | 约 69,340 |

冠军之路平均每场后备经验的近似 95% 抽样置信区间为 **[4,075.15, 4,082.55]**。其野怪战约 1,935 XP/场，训练家战约 6,128 XP/场，最后一场对手战 13,228 XP；最终六只敌人合算一场。

冠军之路每场经验约高 **46.45%**。将走图、治疗等时间分摊到每场后，冠军之路平均每场耗时若低于银河基地的约 **1.465 倍**，其纯击倒 XP/分钟更高，反之银河基地更高。此处直接比较每场，避免把多场数带来的整轮经验总量误认为单位时间效率。

结果见 [victory-road-experience.json](victory-road-experience.json)。单独复现该章节，不覆盖先前两章报告：

```
MAP_CHAPTERS=59 MAP_REPEAT_ONLY=true MAP_OUTPUT=docs/victory-road-experience.json npm run analyze:maps
```

## 复现

```
npm run test:engine
npm run analyze:maps
```

生成器使用原始 Game/Adventure 工厂产生遭遇，只跳过实际战斗过程，因此不宣称得到了 XP/分钟。等级、种族、训练家队伍数量、特殊馆内训练家和额外城镇遭遇都来自原引擎，不将所有训练家简化为一只精灵。基础和在场奖励在每次击倒时分别四舍五入后再累计。

结构化结果见 [map-experience-comparison.json](map-experience-comparison.json)，包含引擎摘要、抽样数、分类、基准/重复两组结果及置信区间。两章目前都没有带 `keep` 标志的首领，故两组只存在抽样波动。
