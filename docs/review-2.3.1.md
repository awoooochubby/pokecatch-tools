# v2.3.1 全量源码快速审查

检查范围：所有手写应用源码、独立模拟引擎适配、Worker 通信、存储迁移、事件采集、Vue 组件、构建与发布流程。生成包和静态精灵数据检查生成一致性，不将其作为手写代码逐行重复审查。

本次修复：

1. **经验模块关闭后重新开启会补计关闭期间的 XP。** 停止时清除经验基线，保存为关闭状态后刷新也不沿用旧基线；重新启用的首次样本只建立基线。恢复后的手动重置也不能拿停止前的旧快照回填经验。
2. **旧经验页使用待生效 team，可能漏掉实际 road 的收入。** 累计、单场及队伍进度统一优先读取实际出战 road，空/未建立 road 时回退 team；刷图实测复用同一规则。
3. **单个订阅处理器异常中断整个事件广播。** 对每个订阅者独立隔离异常并记录错误，其余模块继续接收该样本。
4. **敌人数组内容缺少校验。** 在分发前拒绝空敌人记录和缺失/非数值 HP、编号等结构错误，避免在多个功能内触发异常。兼容原游戏换地区时合法的 road=null。

新增回归覆盖关闭/重启/刷新不回填、实际队伍与计划队伍不同、事件异常隔离、异常敌人记录和原生空 road。原有完整引擎及浏览器流程继续验证。

验证结果：54 项测试、完整 Chromium 回归、TypeScript 检查和三个安装入口的一致性校验通过；浏览器回归确认游戏存档保持原样。

未改变已标明的计算边界：战损和经验期望为独立重复模拟估计；经验预测耗时使用标准行动节奏，不声称前台动画精确计时。需要手动选择、漫游等未适配机制仍明确说明限制。
