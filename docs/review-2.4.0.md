# v2.4.0：联盟数据缺失与对策体验

用户报告：银河队基地可预测，四天王阿柳报 `Cannot read properties of undefined (reading 'id')`。

复现：原适配器创建阿柳章节后，道中训练家节点没有 `team` 字段；第一次进入训练家战时在原函数 De 的空池回退 `i[0].id` 处抛错。真实游戏另外加载 LEAGUE_TEAMS，适配器漏掉此数据，导致进入错误的随机阵容回退分支。

修复：将 LEAGUE_TEAMS 加入摘要固定的依赖提取；共用 ENGINE_DATA_NAMES 初始化两个模拟入口。未替换空池为随意精灵，也没有放宽摘要校验。回归断言阿柳四名道中训练家完整固定队伍，并从真实引擎的生成敌人核对目标 HP；神奥四天王及冠军五章全部做经验预测。

体验调整：章节/当前战斗来源明确区分；推荐卡先展示人类可读结论和理由；中文搜索目标；高级参数折叠；结束后定位结果；章节切换自动刷新，战斗或队伍变化标记过期。

新增路线证据：实际累计扣血、最常见败点、下一中心、剩余场数、同中心区间内最大耗血来源；反例敌人的完整开战状态可带入单挑。单挑推荐比较相同敌人下的当前队伍成员，不拿不同目标混算，也不承诺替换后必过。

验证包括：原缺失依赖用例先失败后通过；联盟五章、当前敌人与固定训练家目标、中心前战败解释、成功路线不捏造原因、反例回送计算、旧功能和真实 Worker 的浏览器回归。

最终结果：60 项测试通过；完整 Chromium 流程通过（含阿柳经验浮窗、中文地图搜索、章节自动更新、过期提示、失败来源到对策卡）；TypeScript、生成包一致性和格式检查通过，游戏存档保持原样。
