# 目标配队：少换人、少练级

入口在“对策 → 读取本章敌情与 Box → 指定目标”。选择保存路线中的节点，区分“到达节点前”与“打完该节点”。到达中心前不回血；经过中心才治疗。规划从本章开头满血出发，使用这次保存的路线；实际重新出发时，游戏可能重新生成节点。分析期间游戏有变化会提示快照过期；再次点配队会自动刷新 HP/XP 等状态，同一章节、轮次及完整节点列表才能沿用原目标，路线变动时提示重选。不会修改队伍或游戏存档。

先用原队伍检查目标。如果通过率保守下界已达 95%，保留原队；否则测试换位、原成员升级、Box 替补及最多两名新成员。保留成员默认保持相对顺序。伤害和速度只用于筛选，包含先后手、命中、伤害浮动、暴击、状态、中心治疗及自动切换的实际连续战斗才决定能否通过。

## 怎么平衡配置改动与练级

先达到目标通过率要求，再比较：

`配置成本 = 预计训练分钟 + 20 × 换入人数 +（保留成员相对顺序改变时加 1）`

20 分钟是偏好权重，不是换人实际要花的时间。比如保留队伍练 10 分钟比换一只、练 5 分钟优先（10 对 25）；保留队伍需要练一小时，则换一只、练 5 分钟优先（60 对 25）。只换位、无需练级的成本为 1。增加空余队伍位置也算新成员。没有可靠训练估时的方案成本为未知，不按零处理。

最终卡片列出队伍顺序、谁下谁上、每只目标等级、所需 XP、练级图和全队一起达到目标的时间，以及目标通过率区间、累计承伤和倒下次数。可以导出完整 JSON 报告。

## 练级时间怎么算

独立原引擎从这支拟议队伍的**当前真实等级与 XP**开始，满血连续重复刷普通地图，保留原伙伴、经验加成和捕捉设置。真实发放战斗 XP、上场奖励、伙伴加成、私有伙伴累计奖励和重复捕捉经验；成员可以逐步升级。记录所有需要训练的成员达到目标等级的第一个行动步。多只成员同时获得经验，时间不相加；不把剩余 XP 除以触顶后的整轮平均效率。

每个方案比较至多三张当前地区已解锁的非联盟普通地图：最近、往前约三章及地区中段。每图 8 次连续训练，保留失败重打时间，每次上限两小时或 20,000 步，均完成才给均值与近似 95% 均值区间。未完成、需手动选择或遇到未适配机制时，明确标记无法估时。地图选择是有限比较，不保证全地图最快；低级图也可能胜出。

重复同一训练地图时不会解锁新章或抬高存档等级上限。按标准行动节奏计时，时钟前进，加成可到期。完成一轮重建同图、治疗计一个行动步。保留当前捕捉设置可能消耗模拟背包里的球，但真实背包不变。不使用糖果、不假设手动进化或更换伙伴。用户须自行把这张普通图设为重复训练目标。

## 搜索和可信度

最多筛选 49 支队伍，每组 128 次，使用同组随机种子比较。原成员测试 +1 / +3 / +5 / 上限等等级，替补也考虑当前等级与少量升级。选择初测达标的少换人、少 XP 和安全性较好的候选，至多 4 个进一步模拟训练并用不同种子独立复核 512 次。并未穷举全部精灵、等级、顺序、地图或两人组合。

要求最终 Wilson 95% 胜率下界达到 95%。筛选结果和独立复核分开，复核未达标只列为排查备选；有限样本不是必胜保证，多个方案比较也不提供整体 95% 保证。没有找到方案不等于数学上无解。

目标路线保留建议等级，禁止战斗奖励偷偷升级，包括绕过公开 gainXp 的私有伙伴奖励；保持读取时自动切换设置，按标准行动节奏推进时钟，计入途中加成到期及天气变化。训练可能让未指定升级的其他成员也提高等级，但目标复核使用其原等级，不额外假设收益。需要训练时，在预计训练结束时刻复核目标；训练估时误差会影响这个出发时刻。训练后的 HP 不延续到目标，假设下一次从章首满血出发。

`npm run test:engine` 包含节点边界、独立样本、少换人、伙伴奖励冻结及首个升级步的原引擎对照；浏览器测试覆盖实际 Worker、界面、报告导出和游戏存档不变。
