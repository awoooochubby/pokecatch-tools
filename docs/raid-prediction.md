# 团体战成功率预测

打开助手“团战”，点击“读取团体战配置”，会列出全部已解锁的今日异色团体战；正在打一场也会读取其余场次，不需要退出战斗。点击“预测全部团体战”逐场计算、并排比较胜率，也可以只预测所选场次。每场使用自己在游戏里为该地区配置的精灵和两名队友。缺少精灵／队友的场次保留在列表并显示原因；单场读取或模拟失败不影响其他场次。

默认 512 次模拟，显示本轮出发击败首领的比例和 95% Wilson 抽样区间。成功指完成道中并击倒首领，不把后续低概率捕获算作战败。即使 512 次全部通过，也会给出有限样本的区间，不代表保证成功。

从入口、原队伍满血、原等级开始，连续模拟两个野生节点、两个训练师节点、原生治疗节点和首领。已经进入战斗时，也按入口重打预测，并非当前残血残局的胜率。首领 HP／威力缩放、属性、先后手、招式选择、命中、暴击、状态、首领怒气与范围攻击都沿用经过哈希校验的原版引擎。加成到期采用游戏非冒险页面的标准行动节奏，不预测人工停顿和前台动画耗时。

参战成员按原生团体战专用队伍读取，自己的精灵保留等级、异色和阶级。NPC 保留存档中的真实 `statMult` 等能力字段；好友按当前版本原生好友适配逻辑读取。不会把冒险六人队误当成团体战队伍，也不会按 UI 槽位顺序猜测实际出场顺序。

原版开战时按候选列表排序组织队友，NPC 在存档中的生成顺序可能与选择槽位不同。预备阶段可精确读取两名 NPC，或一名好友加一名 NPC。两名好友的完整候选顺序没有保存在普通存档中时，分别模拟两种顺序，各做 512 次，显示两种结果范围与覆盖它们的抽样区间，不给未知顺序编造概率权重，也不要求先开战。详情展示较低胜率对应的阵容顺序。已经开战的场次直接使用实际参战顺序。

预测只运行在独立 Worker，不发起团体战，不替换游戏对象，也不回写游戏存档。读取配置会打开原生团体战界面；挂机追踪运行时暂不读取，避免界面自动切换冲突。队伍、队友、加成、首领或日期改变会标记报告过期，重新预测会重读最新配置。

这项功能针对每日异色团体战。社区“世界首领”是另一套规则，未用普通团体战模型外推其胜率。无法确认配置、跨日、环境不匹配或模拟未结算时显示错误，不将未知样本按失败计算。

测试用未改写原引擎对照完整道中与首领结算，并覆盖弱队道中失败、击败与捕获概率的区别、原生 NPC 顺序、已开战实际顺序、过期提示、取消和存档保持不变。
