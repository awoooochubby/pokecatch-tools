# 副本边界和逐节点经验

v2.6.0 把普通章节作为一个副本，把原游戏 `STORY.leagueOf` 返回的联盟全部阶段作为一个副本。神奥联盟是阿柳、菊野、大叶、悟松和冠军的完整流程，包含所有道中训练家。没有硬编码章节编号；其他地区使用同一规则。

## 固定目标与连续战斗

敌情目录和配队下拉框使用稳定副本 ID 与节点语义 key。内部章节切换只更新实时进度，保留目标、敌情目录和已完成报告，不再自动销毁重载。状态变化会把旧报告标记为快照结果，重新配队时刷新存档并按原目标 key 重新定位，不会悄悄改成“下一位四天王”。切换到另一个副本才重新加载目录。

配队默认目标为副本终点，可选中间节点。计算从副本入口满血开始，保持建议等级固定，连续执行道中、首领、状态、自动换人及治疗。章节交接调用原游戏 Adventure.step：原引擎自带的治疗保留，不增加额外治疗。报告记录实际模拟到达的节点次数，能检查计算是否覆盖道中和后续阶段。仍是有限搜索与抽样验证，不保证全局最优。

当前阶段使用存档原节点；其余联盟阶段用已保存的联盟计划和已核验的原引擎构建。首阶段重新构建会随机重置 leaguePlan，因此还原保存的训练家职业，固定名单仍来自原生 LEAGUE_TEAMS。未来随机队伍按原游戏概率生成，不把尚未生成的随机敌人说成确定名单。

模拟选图界面把整个联盟显示为一个选项，计算一整场挑战的 XP 和耗时。兼容旧引擎调用时仍可按内部章节计算；界面请求明确携带 `unit: dungeon`。联盟内正常推进解锁、等级上限和治疗，结算前停止，不自动开始下一个副本。

## 节点经验入口

助手顶部“刷图” → “本图节点” → “计算本图节点经验”。无需实战采集，默认 256 次，可选 128–2048 次。独立 Worker，可取消、导出 JSON，不写游戏存档。

- **整副本重打预估**：以当前队伍等级、XP、伙伴累计进度和加成，从副本入口满血出发；过去节点也会重新估算，不能当作过去实得 XP。各战斗按该节点规则重建，已领取的一次性节点跳过。
- **剩余副本预估**：保留当前节点、我方 HP/状态、敌方剩余 HP 及行动队列，只算后续；过去节点标为未回算，不冒充零收益。联盟从当前阶段继续到冠军。

每行显示节点种类、所属阶段、整队或单只的期望入账 XP、累计 XP，并在存在失败风险时显示到达概率和“到达后的平均入账”。中心、树果和过场通常直接经验为零，但其治疗照常影响之后的战斗。

## 归属、失败和未知值

每次行动**前**记录所属节点；行动结束后用原队伍成员的真实经验/等级变化反推 XP，跨级时加回原生 xpForNext。这样包含战斗分配、在场倍率、伙伴倍率、私有伙伴累计奖励和重复捕获经验，排除触顶溢出。奖励算在触发它的节点，不会因胜利后 node 自增而串到下一处。

整队是当前出战成员实际入账之和，伙伴若在 Box，其额外经验不计入整队。到达概率和完成概率为 Wilson 95% 区间；XP 均值为近似 95% 区间。节点均值之和与同批模拟的总期望一致；界面四舍五入可能有细微差异。

战败样本保留已经取得的 XP；之后确实没有到达的节点对本轮贡献为零，同时把“本轮没到达”和“节点本身不奖励经验”区分开。到达后平均仍包含在该节点中途战败的部分奖励，不是保证完整打赢的奖励。

需要手动选择、特殊首领或其他无法确认的机制出现时，该节点及后续标为**未知**。若任何样本在此阻塞，不按零收益参与后续期望；合计只包含所有样本都可确认的前缀。不会用仅成功样本的收益冒充完整期望。

样本从同一当前快照开始，不累积上一轮升级。时钟按标准行动节奏推进，正常处理中途升级、加成到期及天气变化。前台动画和人为停顿不用于这项 XP 估算。已有结果在路线、战斗、队伍等状态变化后标记过期，下次点击自动读取新快照。

验证包含真实原引擎的节点归属、伙伴奖励、等级上限、当前战斗已倒下敌人、失败、未知前缀，以及联盟连续阶段；浏览器验证整联盟目标不因过场重置、节点 XP 和导出守恒。
